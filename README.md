# OFFGRID – No Signal, No Limits

A 3D cyberpunk game developed during a 24-hour Gameathon based on the theme **"The Matrix – Break the Simulation."**

## 🎮 About
Step into a futuristic cyberpunk world and experience an immersive gaming environment.

## 🛠️ Built With
- Godot Engine 4.x
- GDScript
- GitHub

## ✨ Features
- Cyberpunk-inspired 3D environment
- Neon visual effects
- Immersive audio
- Interactive gameplay

## 👥 Team
Developed collaboratively as part of a 24-hour Gameathon.
