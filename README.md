# OFFGRID-CyberPunk-Racing-Game
Developed **OFFGRID – No Signal, No Limits**, a 3D cyberpunk game during a 24-hour Gameathon using Godot Engine 4.x. Contributed to environment design, asset integration, and audio, creating an immersive futuristic gaming experience.  **Tech Stack:** Godot 4.x, GDScript, GitHub.
